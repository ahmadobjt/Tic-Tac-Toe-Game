Tic-Tac-Toe Game:
A simple Tic-Tac-Toe game made with HTML, CSS and JavaScript.

Features:
- Two-player game
- Simple game interface
- Checks winning conditions
- Detects draw
- Reset game option

Technologies
- HTML
- CSS
- JavaScript

How to Play
1. Player 1 and Player 2 take turns.
2. Select an empty box to make a move.
3. The first player to complete a row, column or diagonal wins.
4. If all boxes are filled without a winner, the game is a draw.

Project
I made this project to practice JavaScript, DOM manipulation and basic game logic.
